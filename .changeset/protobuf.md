Add the experimental `effect/protobuf/Protobuf` module for Protocol Buffers binary encoding and decoding. `Protobuf.toCodec` derives a codec from a schema annotated for protobuf, such as one generated by `protoc-gen-effect`: `Protobuf.Message`s of fields numbered with `Protobuf.field`, `Protobuf.Oneof`, `Protobuf.Enum`, `Protobuf.OpenEnum`, `Protobuf.Map`, extensions, `Any`, unknown fields, and the well-known types.

Add the experimental `effect/protobuf/ProtobufDescriptor` and `effect/protobuf/ProtobufPlugin` modules with schemas for `descriptor.proto` (`FileDescriptorSet`, `FileDescriptorProto`, …) and `plugin.proto` (`CodeGeneratorRequest`, `CodeGeneratorResponse`). Fields a message does not declare, such as custom options, are kept and written back.

Add the experimental `effect/protobuf/ProtobufJson` module for the protobuf JSON mapping. `ProtobufJson.toCodec` derives a JSON codec from the same schemas as `Protobuf.toCodec`, with the options `alwaysEmitImplicit`, `enumAsInteger`, `useProtoFieldName`, `ignoreUnknownFields`, and a `registry` for `Any` values and for extensions, whose JSON key is the full name given to `Protobuf.extension`.
