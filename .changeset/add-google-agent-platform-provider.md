Add `@effect/ai-google-agent-platform`, a Gemini Enterprise Agent Platform provider for the Effect AI SDK. It implements the `LanguageModel` and `EmbeddingModel` services on top of the Agent Platform REST APIs, with OAuth / API key authentication, tool calling, structured outputs, streaming, grounding tools, and support for both text embeddings and `gemini-embedding-2`.
