Take slash commands with no options or one string option, and add `DiscordChat.commandRequests`, which gives the registration payloads of a group's commands. The adapter registers nothing. `normalizeInteraction` now gives `CommandInvoked` for those commands, and a `ModalSubmitted` without a `messageId` for the submit of a modal a command opened, where it gave none for both. `respond` is callback type 4, `defer` type 5 and a modal type 9, with the ephemeral flag when private. A command nobody handles gets no callback, so one another library owns is left to it. `Chat.followUp` edits the original response for 15 minutes. The descriptor lists `commands` and `ephemeral`. A second `followUp` replaces the first answer. `followUp` sends one HTTP request over the layer's `HttpClient`, not dfx's client, and never sends it again, so a 429 fails `RateLimited`. After 15 minutes Discord answers 401 with code 50027, which is `NotFound` with detail `interaction_expired`.
